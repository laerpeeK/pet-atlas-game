每日副本（🌟） ​

  1. 玩家每天可以免费通关各个副本一次，所有副本进度重置时间为每天 00:00 。
  2. 玩家可以在神秘商店使用水晶购买副本通行证，使用后可以再次挑战对应副本。
  3. 每个副本都产出大量的宠物养成道具、装备精炼道具、金币、威望、水晶卡。
  4. 收集副本装备图纸及所需精炼道具，可以打造对应的副本套装！

普通地图 ​

  1. 玩家战胜普通地图的怪物可以获得任务所需收集材料，经验增益道具。

  2. 新大陆地图有几率掉落宠物涅磐道具，旧大陆有几率掉落宠物进化，宠物合成道具。

  3. 玩家可以通过地图介绍看到该地图的出现怪物、 物品掉落详情。

  4. 玩家可以在道具商店购买对应地图的精灵球，在具体战斗时进行怪物捕捉。
