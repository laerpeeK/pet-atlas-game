任务类型介绍 ​

日常任务（🌟） ​

  1. 每天 00:00 刷新，玩家可以完成任务获取到宠物养成、装备打造、商店消费所需的道具及货币。建议所有玩家都将日常任务作为副本通关外的每日游戏目标。
  2. 【日常】好事成双 系列任务可以获取大量修炼秘籍，宠物进化、宠物合成、宠物涅磐道具以及大量金币及威望，金币和威望可以用于道具商店跟铁匠铺的消费。
  3. 【日常】野外狩猎 系列任务可以获取水晶奖励，水晶可以用于神秘商店的消费。
  4. 【日常】探索新大陆 系列任务可以获取较为珍贵的经验增益道具、宠物养成道具、装备精炼，装备强化道具。

兑换任务 ​

  1. 可以将普通地图掉落的进化宝石兑换成进化道具、神秘书页兑换成技能书、副本掉落的收集材料兑换成雪羽凤凰之卵、五系终极宠物卵。
  2. 可以将低品质修炼秘籍、威望道具批量兑换成高品质修炼秘籍、威望道具。
  3. 可以将一定数量的装备碎片与特殊收集材料兑换成装备自选礼包。

宠物专属任务 ​

  1. 玩家携带指定神系宠物可以完成其对应的宠物专属系列任务。

  2. 完成宠物专属系列任务可以获取到威望、水晶与高价值道具。部分神系宠物还有其威力强大的专属装备。

  3. 宠物专属任务完成目标包括：

    • 完成材料收集

    • 剿灭一定数量的普通地图怪物

    • 击败副本 BOSS 若干次
