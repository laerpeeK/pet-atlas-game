版本 2025 第 二 季度 ​

网站链接调整

  • [🔧] 调整宠物图鉴访问地址为：http://127.0.0.1:12000/atlas，弃用旧地址。
  • [🔧] 调整游戏指南访问地址为：http://127.0.0.1:12000/docs，弃用旧地址。
  • [🔧] 限制了请求来源，对不合理的页面请求来源进行了屏蔽，请从 http://127.0.0.1:12000 访问游戏及相关服务。

游戏设定调整

  • [🚀] 玩家登录有效期（下次刷新页面无需输入账号密码）由7天调整为14天。
  • [🚀] 优化客户端版本更新机制。
    • 当需要进行游戏严重漏洞修复，无法与前一个版本兼容的内容更新时。客户端会接受到服务器的最新的更新推送通知，并自动进行页面刷新（这意味着处于挂机状态下的玩家会自动退出挂机状态，并加载最新版本的内容）。
    • 其他场景下的游戏更新方式：玩家自行刷新游戏页面加载新内容。
  • [🔧] 野外探险处于自动战斗状态时，进入下一轮等待时长调整为恒定 5s。
    • 玩家处于自动战斗状态下，无论是否点击【继续冒险】，下一轮怪物的刷新时长为 5s。
    • 玩家不处于自动状态下，手动点击【继续探险】，下一轮怪物的刷新时长为 1s。

服务器优化

  • [🚀] 优化了资源缓存机制。部分浏览器支持二次请求静态资源时直接从玩家本地缓存获取，无需再次下载服务器资源。
  • [🚀] 增加了网页性能监控机制，用户访问游戏时，会有网络请求用于收集 Google 官方列出的页面性能指标数据。
  • [🔧] 统计玩家游戏过程中在页面的点击事件进行上报，不会记录玩家游戏过程及操作路径，当前记录点击次数、点击时间、页面坐标x,y像素点。
  • [🔧] 上报玩家游戏过程中代码的执行错误、违反正常游戏行为的操作进行上报（时间模块）。
  • [🔧] 优化了网站访问日志，这部分日志只对异常访问、爬虫访问、短时间内高频率访问 IP 进行数据分析统计。
